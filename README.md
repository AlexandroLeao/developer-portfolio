
# Developer Portfolio

Professional developer portfolio built with React,
TypeScript, and modern software engineering practices.

## About the Project

This project aims to develop a responsive and accessible
portfolio website to showcase professional experience,
technical skills, certifications, and software projects.

Beyond the user interface, the project will be developed
using software engineering and DevOps practices.

## Tech Stack

- React
- TypeScript
- Vite
- ESLint
- Git and GitHub
- GitHub Codespaces

## Planned Technologies

- Tailwind CSS
- Vitest and React Testing Library
- Playwright
- Docker
- GitHub Actions
- AWS

## Project Status

In development — Initial environment setup.

## Getting Started

### Prerequisites

- Node.js compatible with the installed Vite version
- npm

### Installation

```bash
npm ci
```

### Development

```bash
npm run dev
```

### Production Build

```bash
npm run build
```

### Code Quality

```bash
npm run lint
```

## Development Workflow

This project follows a feature-branch workflow:

1. Create an issue for the task.
2. Create a dedicated Git branch.
3. Implement and validate the changes.
4. Open a Pull Request.
5. Review and merge into the main branch.
